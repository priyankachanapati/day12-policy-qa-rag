# Data Classification

> SYNTHETIC SAMPLE DOCUMENT for training. Brightlake Systems is a fictional company.

## Classification Levels

Information is classified as Public, Internal, Confidential or Restricted.

## Handling Confidential Data

Confidential and Restricted data must be stored only on approved encrypted systems and never on personal devices.

## USB Storage

USB storage devices are blocked by default. Only encrypted drives issued by IT may be used.

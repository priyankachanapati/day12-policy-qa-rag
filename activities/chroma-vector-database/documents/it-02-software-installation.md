# Software Installation

> SYNTHETIC SAMPLE DOCUMENT for training. Brightlake Systems is a fictional company.

## Approved Software

Employees may install software only from the Brightlake Software Centre.

## Requesting New Software

Other software requires approval through a TechDesk ticket. IT reviews licence terms and security risks before approving.

## Unapproved Software

Unapproved software found on a company laptop is removed automatically during the weekly compliance scan.

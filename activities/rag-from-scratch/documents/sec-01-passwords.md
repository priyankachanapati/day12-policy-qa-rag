# Password Requirements

> SYNTHETIC SAMPLE DOCUMENT for training. Brightlake Systems is a fictional company.

## Password Rules

Passwords must be at least 14 characters long and must not reuse any of the previous 10 passwords.

## Changing Passwords

Passwords must be changed every 180 days and immediately if a compromise is suspected.

## Password Manager

KeyVault is the only approved password manager. Passwords must never be written down or shared.
